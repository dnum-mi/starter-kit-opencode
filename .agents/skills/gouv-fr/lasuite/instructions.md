# Groupe `gouv-fr/lasuite` : interfaces LaSuite

> Chargé en plus du socle `AGENTS.md`, par le plugin (`"groups": ["gouv-fr/lasuite"]`) ou par URL : voir le README.

## Périmètre

Composants d'interface de l'écosystème LaSuite (`@gouvfr-lasuite/ui-kit`, Cunningham), utilisés pour les
applications LaSuite.

## Skills

| Skill | Quand l'utiliser |
|-------|-----------------|
| `lasuite-ui-kit` | Interfaces React LaSuite — provider, design tokens, icônes Material, patterns de pages |

## Règles

- Le **provider est obligatoire** pour que les composants s'affichent.
- Les design tokens CSS et la police d'icônes Material se chargent dans l'ordre indiqué par le skill.
- Pour les interfaces **hors LaSuite** qui restent conformes État, utiliser le groupe `gouv-fr/dsfr`.
